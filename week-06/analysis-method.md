# Weekly campaign review

## Input

The data file has one row per campaign per week.
Compare the two weeks the user names, or else the two latest weeks.
Leave the other weeks out.

## Data checks

Before you calculate, check for missing values, negative values, and duplicate rows.
Report any problem. Do not edit the data file.

## Four measures

| Measure                   | Formula                         |
|---------------------------|---------------------------------|
| Click-through rate (CTR)  | clicks ÷ impressions            |
| Conversion rate           | attributed purchases ÷ clicks   |
| Cost per purchase         | ad spend ÷ attributed purchases |
| Return on ad spend (ROAS) | attributed revenue ÷ ad spend   |

## Report

Save a Markdown report with three sections:

1. Comparison table: the four measures for each campaign in both weeks, and the change.
2. Findings: up to three changes to investigate. Write possible causes as questions.
3. Data problems.

Do not recommend budget changes.
